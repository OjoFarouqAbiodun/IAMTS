# IAMTS — Project Documentation

This folder holds the technical and academic documentation for the
**ICT Assets Maintenance & Tracking System (IAMTS)**.

| Document            | Description                                                        |
|---------------------|--------------------------------------------------------------------|
| `ERD.md`            | Entity Relationship Diagram and database design (CSC 394)          |
| `SDLC.md`           | System Development Life Cycle write-up (CSC 392)                   |
| `ARCHITECTURE.md`   | Technology stack, component layout, security controls              |

## Suggested reference / talk order for defense
1. **SDLC.md** – explain the development process and problem statement.
2. **ARCHITECTURE.md** – walk through the stack and request flow.
3. **ERD.md** – describe the tables, relationships, and sample queries.
4. Live demo – run `start.bat`, log in as Admin/Tech/Staff, and show the
   Reports page (charts, filters, CSV/Excel/PDF export).
